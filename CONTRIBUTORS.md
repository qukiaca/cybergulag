## Права уполномоченных участников

Согласно LICENSE v1.2, уполномоченные участники имеют право:

1. **Согласовывать изменения** — любой из участников может approve/merge PR
2. **Указываться в атрибуции** — достаточно указать любой ник из списка
3. **Обновлять список** — добавлять/удалять участников по взаимному согласию

---

## Обязанности уполномоченных участников

1. Проверять код перед мерджем
2. Следить за соблюдением условий LICENSE
3. Не разрешать коммерческое использование без общего согласия
4. Не закрывать исходный код производных работ

---

## Как обновить этот список

1. Предложить изменение через Issue или обсуждение в команде
2. Получить согласие всех текущих уполномоченных участников
3. Внести правки в этот файл
4. Обновить версию LICENSE (если меняются условия)
5. Закоммить с понятным сообщением

Пример сообщения коммита:
  docs: добавить [ник] в список уполномоченных участников
